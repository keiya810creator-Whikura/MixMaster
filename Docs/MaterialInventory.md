# 素材インベントリ

設置した画面UIのButtonへ `MaterialInventoryButton` を追加します。Awakeでクリックを接続するため、OnClickの手動登録は不要です。
装備・図鑑・プリセットと同様に、専用ボタンから開きます。

`Assets/Resources/UI/MaterialInventory/MaterialInventoryPanel.prefab` を初回だけ自動生成し、以後は再利用します。
配置済みの画面がある場合はそれを優先します。Editorメニュー「MixMaster > UI > 素材インベントリPrefabを配置」でも配置できます。
Rootの背面は全画面、カードはSafeAreaLayoutを通して表示します。

## 一覧と詳細

- 現在の所持数が1以上の素材を、アイコン・素材名・3桁区切りの総所持数で横6列に表示します。
- タップするとアイコン・名前・総所持数・ドロップする敵・ドロップするダンジョンを表示します。
- 同じ素材を落とす敵やダンジョンが複数あれば全件を表示し、重複する登録を除きます。
- 詳細の「一覧へ」で戻り、一覧の「閉じる」で閉じます。所持数0の素材は一覧から外します。
- 定義が見つからない保存済み素材もIDと所持数で表示し、入手元は「未登録」とします。

入手元はMonsterCatalogのuniqueMaterialと、MapCatalogのnormalMonsters・bossMonster・旧monsters・dungeonMaterialから逆引きします。
一覧の順序は素材IDの数値順です。比較用の一覧は複製し、所持品やマスターデータを変更しません。

既存MaterialInventoryManagerの所持数と保存処理を使い、セーブ項目は追加しません。
取得・消費・復元を購読し、同一フレーム内の複数通知をLateUpdateでまとめて反映します。
空/nullへの復元もMaterialsRestoredで反映します。詳細中の素材が0になったら一覧へ戻ります。
画面を閉じた際に購読を解除し、開き直すと現在の所持数を読み直します。
一覧は図鑑のEncyclopediaGridUI/Cellを使い、表示行と余白2行のセルだけを生成・再利用します。

素材取得ログの末尾の総所持数も、`素材名×3 (123,456)` の形に変更します。桁区切りは実行端末の言語にかかわらずコンマです。

## 確認

変更した全ランタイムクラスと新Editor配置処理を、Unity API代替環境でメソッド抽出せずコンパイルして59項目成功。
新規Prefabと既存転生Prefabの実フィールド/参照を読み込み、ボタンからの表示・素材セル選択・所持数増減・まとめ更新・上限・空の復元・閉じる/再利用・600件のスクロール・200回のスクロールで追加セル生成なしを確認しました。
同じ検証で、転生先のスキル一覧/詳細/未対応除外・旧パネルへの補完・実習得条件・プレビュー非変更、ダメージだけの半サイズとフランス語カルチャーでのコンマも確認しました。
移動/描画/TMPレイアウト・未変更のPlayerManager等は代替APIです。Unityのインポーターや描画を再現した検証ではありません。

Unity Editor本体の全体コンパイル・Prefabインポート・Play Mode・実機表示は未実施です。Unityでは次を確認します。

1. ButtonへMaterialInventoryButtonを追加してPlayし、素材の取得/消費と一覧・詳細の数値が一致すること。
2. モンスター素材とダンジョン素材の入手元、所持0の消去、閉じて開き直したときの更新。
3. 転生の祭壇で人間/モンスターの書を切り替え、ステータスの下のスキル名から詳細を開閉できること。
4. 通常/会心/弱点のダメージ文字だけが前回の半分で、回復・状態文字の大きさと文字色が維持されること。
