# 設定画面

## 接続とPrefab

設置するUI Buttonに `GameSettingsButton` を追加する。OnClickの手動設定は不要。ボタンのCanvas内へ `Assets/Resources/UI/Settings/GameSettingsMenu.prefab` を初回だけ生成し、閉じて再度開いたときも同じ画面を再利用する。HUDのボタンやインベントリ項目は自動追加しない。

画面を先に置いて編集する場合は、Canvasを選択して `MixMaster > UI > 設定画面Prefabを配置`。既に置いた画面があれば選択し、設定を上書き・重複生成しない。事前配置した画面はPlay開始時に閉じる。画面全体・メニュー・7行・チェック枠・説明・戻る/閉じるボタンはPrefabで編集できる。SafeAreaLayoutを通して1080×1920の基準領域内に収める。

## メニュー

ボタンから「設定」を開き、次の7項目を表示する。

| 入口 | 動作 |
| --- | --- |
| 音量設定（未実装） | 準備中ページを開く |
| その他設定 | 今回実装した7つの表示設定を開く |
| プレイ記録・配合履歴 | 統計と最新200件の配合履歴を開く |
| 目標リスト | モンスター・装備・素材の所持目標を登録する |
| ヘルプ | 現在の仕様を14項目で確認する |
| クレジット（未実装） | 準備中ページを開く |
| お問合せ（未実装） | 準備中ページを開く |

子ページの「設定メニューへ戻る」で7項目へ戻り、「閉じる」で画面を閉じる。再度開いたときはメニューを表示する。未実装の入口では音声・クレジット本文・メールや外部サイトへの遷移を行わない。

## その他設定

**チェックあり＝表示をOFF、チェックなし＝表示する。** 初期値は7項目ともチェックなし。変更は即時反映し、自動保存する。

| 設定 | 対象 |
| --- | --- |
| 素材取得時の素材表示をOFF | 素材取得ログの名前・数量・総所持数。素材の取得や所持品は変えない |
| ダメージテキストをOFF | プレイヤー・仲間・敵へのダメージ数値 |
| 回復テキストをOFF | HP回復量の文字 |
| バフテキストをOFF | 攻撃力20％UPなどの文字 |
| デバフテキストをOFF | 防御力15％Downなどの文字 |
| スキルエフェクトをOFF | スキル発射物・範囲陣/衝撃波/爆発の見た目と命中時effectPrefab |
| 攻撃範囲をOFF | プレイヤーと仲間の攻撃範囲の円を一括切り替え |

素材ログと各文字は既に表示中のものも消し、OFF中の取得/文字を再表示時にまとめて再生しない。再表示後は次の取得・発生から表示する。既存の行/文字プールと表示上限を保持し、OFF中は新しい文字/ログを生成しない。ダメージのヒット粒子と発動スキル名はそれぞれの既存表示を維持する。

スキルはRenderer.forceRenderingOffで描画のみ切り替える。SpriteRenderer・ParticleSystemRenderer・Trail/Line/Mesh等の子Rendererが対象。投射物のGameObjectやスクリプトを停止せず、移動・命中・範囲・周期効果・回復・付与・寿命を維持する。表示中のエフェクトも切り替わり、再表示ではまだ寿命内のものを描画する。Prefabで元から無効なRendererやforceRenderingOff指定は保持する。エフェクトの生成・シミュレーション自体は継続する。

攻撃範囲は新しい全体設定が従来のInspector `visible` や個体の `hideAttackRange` より優先する。チェックなしなら従来の個別値にかかわらず生存中のプレイヤー/仲間の円を表示し、チェックありなら全て隠す。死亡した仲間やSpriteなしは表示しない。個体別トグルは詳細画面で隠し、旧フィールド・セーブ値・Prefab参照は互換性のため残す。DisplaySettingsManagerのない旧構成では従来の個別値を使用する。

## 保存と互換性

GameSaveData v17で追加した `displaySettings` に7つの非表示フラグを保存する。Capture/Restoreはコピーを使い、UIから保存データの参照を直接変更させない。旧セーブ・欠落/nullは全表示が初期値になる。復元時は戦闘/編成データより先に設定を反映し、復元だけでは保存しない。既存の図鑑・パーティプリセット等の保存を維持する。

変更時は既存SaveManagerのJSON/バックアップ経路へ保存する。保存失敗でも現在の表示へは反映し、設定ページに再試行中の文言を出す。1秒ごとにunscaledTimeで再試行し、既存の自動保存で成功した場合も保留表示を解消する。同じ値を再設定しただけでは再保存/再通知しない。BootstrapがDisplaySettingsManagerを追加するため、既存Manager設定Prefabを作り直す必要はない。

## 検証とUnity確認

Unity API代替環境で実設定データ/Manager・SaveManager・画面/ボタン・DamagePopupText・MaterialDropLogUI・PlayerAttackRangeIndicator・SkillEffectVisibility・SkillProjectile/ProjectilePathと実PlayerManagerの回復をコンパイルし182項目成功。7項目の独立性、既存文字の即時消去、1000回の非表示ログ/ダメージ、プール再利用、全体範囲の優先、描画中/非表示中の移動・命中・周期効果、JSONファイル/バックアップ/旧v16/null/部分フィールド、保存失敗→再試行、7入口と戻る/閉じる/画面再利用を含む。実SkillActor.Executeのメソッドを抽出した代替検証で、命中時Prefabの表示切り替えとダメージ/回復/付与の継続も確認した。未変更のActor/描画/シーン協調APIは代替実装であり、Unityの描画・物理・全体コンパイルを保証するものではない。

パーティプリセットの既存代替テスト98項目も成功。全198 C#をPlayer/Editor構成で構文確認しエラー0。Prefabの245ドキュメントの一意ID、内部参照、7つの独立Toggle、フォント/スクリプトGUID、行の収まり/重なりを検査した。

Unity Editor本体がないため、Editor全体コンパイル・Prefabインポート・Play Mode・実機表示は未実施。Unityでは設置ボタンにGameSettingsButtonを追加し、次を確認する。

1. メニューの7入口、戻る/閉じる、再度開く操作。
2. 各チェックをON/OFFし、文字と素材ログが個別に消え、再表示後の新しい取得/効果で表示されること。
3. スキルエフェクトをOFFにしても攻撃・回復・バフ/デバフ・陣の周期効果が続くこと。寿命内に再表示した場合の見た目。
4. 従来の個体別設定にかかわらず全体の攻撃範囲が切り替わり、死亡した仲間の円は表示されないこと。
5. 再起動・マップ切り替え後にも7項目が保持され、狭い画面やノッチ付き画面でもボタンと文字が収まること。
