# オフライン報酬

画面右上の「記録モード（3分）」で、180秒間に実際に増えた素材・ゴールド・経験値を記録します。
記録中は残り時間と「記録を中止」を表示します。アプリがバックグラウンドになると記録は中断し、従来の報酬設定を維持します。
通常のプレイ報酬はその場で所持品へ入り、記録用に二重付与しません。

終了すると素材ごと・ゴールド・経験値の1分当たり取得量を表示し、
「これでオフライン報酬を上書きしてもよろしいですか？」と確認します。
「上書きする」の保存成功後に新設定へ切り替えます。「今回は変更しない」または×では旧設定を維持します。
確認待ちの記録も保存するため、終了直後にアプリを閉じても再表示できます。

計算式は各資源について以下です。

`付与量 = floor(3分間の取得量 × 放置秒数 / 180 × 0.5)`

1分当たりの表示は3分間の取得量÷3です。計算には丸め前の取得量を使用し、実際の付与時に端数を切り捨てます。
例：3分間でゴールド180・経験値360・素材6なら、10分放置でゴールド300・経験値600・素材10です。
放置時間の上限は設けていません。素材の所持上限999,999、ゴールド等のlong上限は従来通りです。
受取画面には上限適用後に実際に増えた数量を表示します。

経験値は主人公の獲得イベントで1回だけ計測し、レベルアップ時の経験値ゲージリセットやパーティ人数では取得率を変えません。
オフライン経験値は通常の戦闘と同様、主人公と復帰時のパーティ各個体に同量を付与します。
素材とゴールドは正の増分を記録し、消費・支出・ロードによる復元は取得数へ加算しません。
素材の所持上限で入らなかった数量も計測対象外です。

起動時は保存済みチェックポイントからのUTC経過時間を使用します。
アプリのpause/focus通知は1つの離脱状態へまとめ、通知が重複しても同じ時間を再度付与しません。
報酬と消費済みチェックポイントは同じセーブに保存します。通常プレイ中の自動保存も基準時刻を更新します。
フォーカスを失ってもUnityが動作し続ける場合、動作中のフレームを放置時間から除外します。
時計が巻き戻った場合は0秒として扱います。報酬設定が未確定なら付与しません。

保存バージョンは11です。旧セーブはsavedUtcを離脱時刻として引き継ぎます。
従来の素材・装備・モンスター・転生・スキルポイントを維持します。

## 配置・編集

`Assets/Prefab/UI/OfflineRewardsHUD.prefab` をMainSceneのCanvas下へ配置しています。
記録ボタン・中止ボタン・確認／受取パネルを含む、Hierarchyで編集可能なPrefabです。
別のCanvasにも同じPrefabを配置できます。毎回のUI生成は行いません。
取得量の一覧はスクロールに対応し、素材名はモンスター／マップのカタログから解決します。

`OfflineRewardManager` は既存のGameManagersに含まれています。
`SaveManager` がロード完了・バックグラウンド移行・復帰・終了を通知します。
`OfflineRewardRules` は取得率、計算、入力の検証とプロフィール複製を担当します。
