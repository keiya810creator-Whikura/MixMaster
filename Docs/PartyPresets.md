# パーティプリセット

## 接続

設置したUI Buttonへ `PartyPresetButton` を追加する。OnClickの手動設定は不要。最初のクリックで専用画面を開き、以後は同じ画面・20行を再利用する。インベントリへは追加せず、新しいHUDボタンも自動生成しない。

Prefabは `Assets/Resources/UI/PartyPresets/PartyPresetPanel.prefab` と `PartyPresetRow.prefab`。画面・名前入力・内容プレビュー・確認パネル・一覧行はPrefabで編集できる。事前配置する場合はCanvasを選択して `MixMaster > UI > パーティプリセットPrefabを配置`。配置済みPrefabを上書き・重複生成しない。

## 操作

1. 一覧の01〜20から保存先を選ぶ。
2. 名前を入力して「保存」。保存済みの枠では「上書き保存」となり、確認後に現在のパーティへ更新する。
3. 保存内容を確認して「呼び出す」。確認後にモンスター・スキル・装備をまとめて切り替える。
4. 「名前変更」で名称だけを変更。「削除」は確認後にプリセットだけを削除する。所持モンスターや装備は削除しない。

名前は最大40文字。空の保存名には「プリセット01」等を使い、空の名前変更は拒否する。削除した枠は再利用できる。確認中にプリセット自体が更新された場合、古い確認操作は実行しない。

## 保存内容

| 対象 | 保存するもの |
| --- | --- |
| 仲間 | 所持個体のuniqueId、並び順、個別の戦闘行動 |
| パーティ | 一括指示 |
| プレイヤーと仲間 | 5つのスキル枠、発動条件・閾値・追加条件・優先度 |
| プレイヤーと仲間 | 3つの装備枠に装着した装備のuniqueId。空枠の位置も保持 |
| プリセット | 保存先、名前、保存日時 |

種族が同じ別個体への置換、スキルの再習得、装備の生成はしない。レベル・経験値・個体値・称号・スキルポイント・HP/MPはプリセットへ復元する値として保存しない。装備の強化後は同じ現物を参照するため、現在の強化状態を使う。

## 呼び出し

全件を確認してから設定を変更する。個体の消失（売却・配合）、装備の消失、未習得/削除済みスキル、重複個体/装備/スキル、不正な条件等は呼び出しを中止し、不足内容を表示する。設定を途中まで適用しない。壊れた記録も上書き・削除で整理できる。

別の個体が装備中の現物は、保存先の個体へ付け替える。保存構成と無関係な控えのスキル・装備は保持する。置き換えられた装備も所持品に残る。イベントは設定一式を変更した後に通知する。

同じ個体が編成に残る場合はActorを作り直さず、現在のHP/MP・生死・状態効果を保持する。新たに編成される個体の出現は既存の編成追加処理を使う。装備変更による通常のステータス補正は適用する。同じ装備構成の再呼び出しでは装備再計算を通知しない。

スキルの再使用待ち時刻は保持する。枠が実際に変わったActorでは旧詠唱と発動条件カウントを取り消し、既存のバフ/デバフ・共通待機は保持する。スキルの学習状態・ポイントを変更しない。

## 保存と互換性

GameSaveData v16の `partyPresets` に保存し、既存のJSON・バックアップ・一時ファイル経由の保存を利用する。保存・上書き・名前変更・削除・呼び出し直後にSaveManagerへ保存を依頼し、失敗した場合はメッセージを表示して再試行する。旧セーブや欠落/nullのフィールドは空のプリセット一覧になる。保存先は0〜19へ制限し、復元時の重複・範囲外の記録を除く。

Bootstrapが既存の設定PrefabにもPartyPresetManagerを補うため、Manager Prefabの作り直しは不要。

## 確認

Unity API代替環境で、実PartyPresetManager・MonsterManager・EquipmentManager・SkillProgressionManager・PlayerManager・SaveManager・PartyFieldSpawnerとUIクラスをコンパイルし、20枠、保存/上書き/名称/削除、深いコピー、一括切り替え、欠品時の中止、既存Actorの保持、CD、旧セーブ、JSONファイル、バックアップ、専用ボタンと確認操作を98項目検証した。実キャンセル処理を抽出した検証と、ファイル書き込み失敗からの再試行も含む。

Unity Editorの全体コンパイル、Prefabインポート、Play Mode、実機表示は未実施。Unityでは専用ボタンにPartyPresetButtonを追加し、2種類の構成を保存→切り替え→再起動後に呼び出すこと、上書き/削除のキャンセル、売却済み個体/装備がある場合の中止、確認画面と名前入力、SafeArea内の表示を確認する。
