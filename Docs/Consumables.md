# 消耗品ショップ・アイテム

## 価格とアイテム画像

`Assets/Resources/Consumables/ConsumableCatalog.asset` を選択し、Inspectorの各アイテムの **Purchase Price** を指定してください。初期値の `-1` は価格未設定で購入不可、`0` は無料、正の数は1個あたりのゴールドです。

HP・MPポーションは下200／中1,000／上5,000回復です。回復対象は主人公で、最大HP・MPを超えず、満タン時や主人公が倒れている場合は消費しません。ショップでは1個・10個・100個単位で購入できます。

鈴の表示名は今回の指定に合わせて「魔よけの鈴」にしています。効果は引き寄せで、カタログのDisplay Nameから「魔寄せの鈴」などへ変更できます。1回使用すると、そのマップの全魔物が60秒間主人公を狙い、通常の索敵・追跡距離を超えて接近します。効果中に出現した魔物にも適用し、終了後は通常の索敵へ戻ります。再使用は残り時間を60秒に戻します。常時使用・課金設定はありません。

鈴の時間は実時間で進み、アプリをバックグラウンドへ移しても延長されません。アプリの再起動・セーブの再ロードで効果は終了します。

先ほど生成した画像を `Assets/Resources/Consumables/Icons/` に512×512の透過Spriteとして設定済みです。画像は各定義のIconから差し替えられます。

## 消耗品屋への接続

MainSceneにはショップ・インベントリ・右上HUDを配置済みです。消耗品屋の建物を配置したら、それを選択し、メニュー **MixMaster → Map → 選択した消耗品屋にアクセスTriggerを追加** を実行してください。入口付近のTrigger、ショップへの接続、UI配置を行います。既存の建物の当たり判定は残します。再実行で同じTriggerを更新できます。

手動で入口を配置する場合は `Assets/Prefab/ConsumableShopAccess.prefab` を入口前に置き、BoxCollider2Dの範囲を調整してください。プレイヤーが触れるとショップを開き、閉じると移動とジョイスティックを戻します。

別シーンでUIを使う場合は **MixMaster → UI → 消耗品UIを配置・接続** を実行できます。

## 編集用Prefab

| Prefab（Assets/Prefab/UI） | 用途 |
| --- | --- |
| ConsumableShopPanel | ショップ・購入数・ゴールド・商品リスト |
| ConsumableInventoryPanel | アイテム使用、自動使用、ショートカット登録 |
| ConsumableItemRow | 共通の商品・所持アイテム行 |
| ConsumableShortcutsHUD | 右上5枠・アイテムボタン・鈴の残り時間 |
| ConsumableShortcutSlot | 1枠分のアイコン・所持数・即使用ボタン |

パネルの操作部分はSafeArea以下で編集できます。HUDの位置は `SafeArea/ShortcutsBar` で変更します。各枠は共通スロットPrefabの入れ子なので、そのPrefabの編集も反映します。

## 自動使用とショートカット

「アイテム」ボタンでインベントリを開きます。HP・MPそれぞれ、自動使用のオン／オフ、使うポーションの種類、残量0〜100％の条件を設定できます。条件以下なら1秒ごとに各種類1個を使用し、指定した種類の在庫がなくなると止まります。別のグレードは自動消費しません。死亡中・ゲームの時間停止中・オフライン中は自動使用しません。

登録するアイテムの「登録」を押し、下部の1〜5枠を選択します。同じ枠へ同じアイテムを指定すると解除でき、別の枠へ指定すると移動します。右上の枠はタップで即使用し、所持数0なら使用不可になります。登録自体は残るので、再購入すれば使えます。

所持数、5枠の登録、自動使用の全設定を保存します。旧セーブは所持品0・未登録・自動使用オフで開始します。

## 確認

購入の金額計算・所持上限、回復と満タン時の保護、HP/MPの自動使用、鈴の遠距離・新規出現への適用と終了、保存互換、即使用と建物UIの開閉を、本番クラスとUnity APIのテスト用代替で検証しています。Unity EditorのPlay Modeと実機での描画・操作確認は、この環境では実行していません。
