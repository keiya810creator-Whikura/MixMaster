# 共通発射物の設定

## 表から番号付きPrefabを自動生成する

`MixMaster → スキル → Excel・CSVを選んで取り込む` で、一回の取り込み中に次を実行します。

1. 全スキル行、発射物の素材選択・固有画像・見た目設定を検証。
2. 発動形式が「発射物」の行から `Assets/Resources/Skills/Projectile/1.prefab` のように、正規化したスキル番号名のPrefabを生成・更新。
3. 従来どおりSkillSOを作成・更新し、生成したPrefabを `projectilePrefab` へ自動設定。

画像は `Assets/素材/Projectile`（旧綴り `Profectile` も対応）の内部またはサブフォルダへ置き、Texture Typeを **Sprite (2D and UI)** にします。画像の自動生成は行いません。

現行ExcelのDT列 `発射物_素材` で、光の弾／衝撃波／魔方陣／斬撃／光の柱／煙と粒子／固有スプライトを選びます。
`発射物_素材` に記載したSprite名を、そのままフォルダ内から自動取得します。例えば「光の弾」は `光の弾.png` のSpriteを使用します。ファイル名（拡張子なし）またはSprite名を一致させてください。共通6種類以外の名前も読み込めます。番号へのフォールバックや接頭番号の自動除去、魔法陣／魔方陣の読み替えは行いません。同名のSpriteが複数ある場合や未配置の場合は更新前に停止します。列名の全角アンダースコア `発射物＿素材` も対応します。新しい素材列がある表では空欄はエラーとなり、その列のない旧表だけ従来の画像番号・スキルID指定を使用します。

固有スプライトを選んだ場合、DX列 `発射物_固有スプライト` に画像ファイル名（拡張子なし）、Sprite名、または `Assets/素材/Projectile/固有/竜の炎.png` のようなアセットパスを記載します。Multiple画像は `Assets/素材/Projectile/固有/炎.png#炎_0` のようにSprite名まで指定します。重複する名前はパスで区別してください。

DF列 `発射物_色` は `#RRGGBB` または `#RRGGBBAA`。白素材へ色を乗算し、末尾AAで透明度を設定します（FF＝不透明、B3＝約70％）。元の色を残したい固有画像は `#FFFFFFFF` を指定します。素材選択はスキルアイコンの画像パスとは独立しています。

画像不足・番号重複・入力不正は、アセットの更新前に行番号とスキル番号を表示します。
再取り込みでは同じパスへ保存し、Prefabおよび既存SkillSOのGUIDと参照を維持します。
「即時」に変更した行はSkillSOの発射物参照を解除します。削除した行や以前のPrefab自体は自動削除しません。

生成Prefabのルートは番号名、共通スクリプトは `SkillProjectile`、画像は子 `Visual` のSpriteRendererです。
Collider/Rigidbodyは不要で、命中半径と移動区間から判定します。
速度・寿命・ダメージ・追加効果は従来どおりSkillSOへ保存し、発射時に共通実行処理から渡します。

| Excel/CSV列 | 反映先 | 空欄の初期値 |
| --- | --- | --- |
| 発射物_表示倍率 | ルートの均等スケール | 0.3 |
| 発射物_色 | SpriteRendererのColor。#RRGGBB / #RRGGBBAA | #FFFFFFFF（白・不透明） |
| 発射物_描画順 | SpriteRendererのOrder in Layer | 60 |
| 発射物_画像角度 | 画像のローカルZ角度（度） | 0 |

動作欄の空欄は共通スクリプトの初期値へ戻ります。前回生成したPrefabの手編集値は引き継ぎません。
一時的にInspectorを変えても、再取り込みで表の設定に戻ります。継続したい設定は表へ記載してください。
`発射物プレファブパス` は任意の**複製元テンプレート**として使用できます。指定した場合も、番号付き出力を作りSkillSOには生成先を紐付けます。テンプレート自体は変更しません。空欄なら標準構成・初期値を使用し、生成先自身を指定した場合も初期値から再構成します。

## テンプレートを用意する場合

`Assets/Resources/Skills/CommonSkillProjectile.prefab` を複製して使います。
SpriteRendererのSprite、色、サイズを変え、共通スクリプト `SkillProjectile` はそのまま使用してください。
発射物の見た目はスキルのアイコンから独立しています。設定したスプライト・色を発射時に上書きしません。
見た目が未設定の場合だけ、従来の簡易表示を使います。
画像が上向きの状態を基準に進行方向を向きます。必要なら子オブジェクトで画像の向きを調整できます。
「回転させる見た目」に子Transformを指定すると、親は進行方向を向き、子だけが回転します。

CSVの `発射物プレファブパス` に、複製元Prefabのプロジェクト内パスを指定します。
例：`Assets/Prefab/FireProjectile.prefab`。通常の番号付き生成では空欄で構いません。
Sprite・色・均等スケール・描画順・画像角度は表の値（空欄は上記初期値）へ更新します。
共通スクリプトはPrefabのルートに、SpriteRendererはルートまたは子に配置してください。
ColliderやRigidbodyを追加しなくても、CSV/Inspectorの命中半径を使って判定します。
高速弾も移動区間を調べるため、移動先だけの判定によるすり抜けを防ぎます。

## 設定の優先順位

1. CSVに指定した項目を使用。
2. 動作の空欄は、複製元テンプレートの既定値。テンプレートがなければ共通スクリプトの初期値。
3. `無効` は明示的なOFF。空欄とは違います。数値の0も明示的な指定です。

Prefabの設定を発射時にコピーするため、同じPrefabで別の動きを持つスキルを使用できます。
PrefabやSkillSOを発射中に書き換えません。
設定UIのMP不足メッセージ、スキル説明、トリガー、表の列名を「MP」へ変更しました。
魔法攻撃力という能力値はMP残量と別です。旧列名 `消費魔力` は互換用として取り込めます。

## CSVの列

従来の `発射物速度入力`、`発射物寿命入力秒`、`追尾入力` は継続して使用します。
即時スキルでは速度と寿命は0、追尾は無効になり、以下の発射物設定を使用しません。

| 列 | 内容 |
| --- | --- |
| 発射物_移動タイプ | 下記14種類から選択 |
| 発射物_貫通 | 有効／無効。命中後も飛び続ける |
| 発射物_回転／発射物_回転速度 | 有効／無効、度毎秒。負数は逆回転 |
| 発射物_蛇行／発射物_蛇行幅／発射物_蛇行回数 | 追加の蛇行、横幅、毎秒の回数 |
| 発射物_加速／発射物_加速度／発射物_最高速度 | 追加の加減速。負の加速度で減速 |
| 発射物_命中半径 | 命中判定の半径。0より大きい値 |
| 発射物_追尾旋回速度 | 追尾の曲がりやすさ |
| 発射物_拡大速度／発射物_最大拡大倍率 | 拡大直進時の毎秒倍率増加、最大倍率 |
| 発射物_直進秒／発射物_帰還速度 | ブーメランの直進時間と帰還速度 |
| 発射物_周回秒／発射物_周回半径／発射物_周回角速度 | 使用者の周囲を回る設定 |
| 発射物_追尾開始秒 | 遅延追尾が追尾を始める時間 |
| 発射物_螺旋角速度／発射物_螺旋拡大速度 | 螺旋の角速度と半径の増加速度 |
| 発射物_往復距離／発射物_反転回数／発射物_反転終了で消滅 | 往復の設定 |
| 発射物_使用者に追従 | その場・地雷・収束成長が使用者の位置に追従する |
| 発射物_再命中／発射物_再命中間隔秒 | 同じ相手に繰り返し当たる設定。最短0.02秒 |
| 発射物_収束秒／発射物_収束最大拡大倍率／発射物_収束最大威力倍率 | その場で徐々に大きく強くなる設定 |
| 発射物_時間切替／発射物_切替秒／発射物_切替後移動タイプ／発射物_切替後速度 | 一度だけ移動タイプを切り替える |
| 発射物_連鎖／発射物_連鎖回数／発射物_連鎖半径／発射物_連鎖威力倍率 | 命中後、未命中の近くの相手へ連鎖する |
| 発射物_分裂／発射物_子弾数／発射物_分裂角度／発射物_子弾威力倍率／発射物_分裂世代数 | 同じスプライト・設定の子弾を生成する |
| 発射物_命中時爆発／発射物_停止時爆発／発射物_爆発半径／発射物_爆発表示秒 | 周囲へ効果を与え、拡大・フェードして消える |

移動タイプは、直進／追尾／拡大直進／その場／ブーメラン／周回後に射出／蛇行／加速／減速停止／遅延追尾／螺旋／往復／感応地雷／収束成長です。

- 直進に「追尾入力＝有効」を組み合わせると、従来の追尾弾になります。
- 周回中は命中判定をしません。周回後に対象へ射出します。
- ブーメランは主人公固定ではなく、そのスキルの使用者へ帰還します。敵・仲間も同じ仕様です。
- その場型で継続攻撃したい場合は「再命中＝有効」。再命中を使わない貫通弾は一体に一度だけ当たります。
- 感応地雷は対象が命中範囲へ入ると爆発します。
- 再命中では範囲効果で巻き込まれた相手にも同じ間隔を適用します。
- 連鎖は既に直接命中した相手を検索から除外し、距離の近い順に次の相手を選びます。
- 重なる範囲や爆発で同じ相手へ同時に二重の基本効果・追加効果を与えません。明示した再命中は別です。
- 分裂は初期値で一世代だけです。CSVの子弾数は最大16、世代は最大3、同じ元弾からの生成総数は64までに制限しています。
- 子弾や連鎖でMPや再使用時間を再消費しません。元の使用者・発射時能力を引き継ぎます。
- 威力倍率は基本ダメージ・回復へ適用し、バフ/デバフ/状態異常の量は既存の追加効果欄で指定します。

## 設定例

| 例 | 設定 |
| --- | --- |
| 回る追尾弾 | 追尾入力＝有効、発射物_回転＝有効 |
| 拡大する直進弾 | 追尾入力＝無効、移動タイプ＝拡大直進、最大拡大倍率＝2 |
| ブーメラン | 移動タイプ＝ブーメラン、貫通＝有効、直進秒＝0.8、帰還速度＝12 |
| 味方に追従する攻撃範囲 | 移動タイプ＝その場、使用者に追従＝有効、再命中＝有効、再命中間隔秒＝0.5 |
| 命中して分裂する弾 | 分裂＝有効、子弾数＝2、分裂角度＝50、子弾威力倍率＝0.5 |
| 連鎖する弾 | 連鎖＝有効、連鎖回数＝4、連鎖半径＝8、連鎖威力倍率＝0.85 |

表の接頭辞 `発射物_` は設定例では一部省略しています。実際の列名は一覧どおりです。
提供された別ゲームのTriggerProjectileを参考に、このゲームのSkillActorと共通ダメージ・追加効果へ接続しています。
別ゲーム固有のEnemy/BattleManager、ノックバック、ローカライズキー、任意の子弾別Prefabなどへは依存しません。


## 画像番号の明示指定

スキル表の `発射物_画像番号` を指定すると、その番号のSpriteを使用します。空欄は従来どおりスキルIDと同じ番号です。例えばスキルID39、画像番号3なら `39.prefab` を生成して `素材/Projectile/3.png` のSpriteを設定します。スキルIDやSkillData参照は変わりません。画像番号は正の整数とし、不在・重複の検査は従来と同じです。

衝撃波や陣のような静止した表示も、発動形式を「発射物」、移動タイプを「その場」にします。即時のままでは番号画像のPrefabは生成されません。発射物速度入力には1などの正数を指定してください。効果の発生タイミングは「生成時」または「一定間隔」で指定できます。
