# 装備強化

鍛冶屋に触れると、強化ボタンが有効な装備インベントリが開きます。
装備を選び、「強化」を押すと強化画面が開きます。
通常メニュー・仲間の装備変更から開いたインベントリでは強化ボタンを非表示にします。
鍛冶屋のインベントリを閉じると、強化の許可と移動・ジョイスティックのロックを解除します。
タップで1回、長押しで連続購入します。指を離す、ボタン外へ移動する、
画面を閉じる、費用が不足する、＋50に達する、のいずれかで停止します。

## レベルと能力値

- 取得時のLvに最大50を加算します。Lv20なら70まで、Lv100なら150までです。
- `EquipmentRecord.originalLevel` が取得時Lv、`enhancementCount` が購入済み回数です。
- 既存の `level` は取得時Lv＋強化回数を保持します。
- 能力値・耐性・ドロップ率は従来の「基礎補正×装備Lv」で計算します。
- 主人公・仲間が装備中でも強化でき、既存の装備変更イベントで能力値を更新します。
- ドロップ時のLv範囲は従来通り1～100です。
- 旧セーブの装備Lvを取得時Lvとして引き継ぎ、強化済みLv150も保存・復元できます。
- 装備一覧・選択詳細の名前は「草原の獣牙剣 Lv101 《レジェンダリーレア》 +1」の形式です。未強化は+0を表示します。
- エピックレア（Lv86～95）は赤系、レジェンダリーレア（Lv96～149）は従来のエピックと同じ紫、ゴッドレア（Lv150）は従来のレジェンダリーと同じ金色です。
- レア度絞り込みにもゴッドレアを追加し、Lv150の装備を抽出できます。

## 費用

初回Goldは装備の出身マップのボスEnemy IDの数値部分です。
例：`MON_006` は6G。2回目からは直前のGold×1.2を毎回切り上げます。
そのマップにいる全モンスターの素材6種を、それぞれGold÷6の切り上げ個数消費します。
ダンジョン固有素材は消費しません。

MAP1のGoldは6、8、10、12、15、18、22、27、33、40…と増えます。
50回目は61,212G、50回の累計は367,152G、各素材の累計は61,207個です。

現在の討伐報酬コードは「ID数値×敵Lv、称号付きはさらに2倍」です。
今回の強化費用は指定例の6Gに合わせ、ボスID数値を基準とします。

全費用を確認してからGold・素材・Lvをまとめて更新し、その後に通知します。
いずれか1種類でも不足すると、他の素材やGoldも消費しません。
連続購入中の保存は既存の `HoldToUpgradeButton` により購入操作の終了時に行います。
既存のアプリ一時停止・終了時の自動保存も利用します。

## マップ設定

配置済みの鍛冶屋をHierarchyで選択し、
「MixMaster > Map > 選択した鍛冶屋にアクセスTriggerを追加」を一度実行してシーンを保存します。
入口前に接触Triggerを作り、既存の装備インベントリと建物UIルーターを接続します。
途中で設定に失敗した場合も、同じメニューを再実行すると既存の
`BlacksmithAccessTrigger`を再利用し、不足するコンポーネントを追加します。
鍛冶屋本体・作成済みTriggerのどちらを選択しても再設定できます。
建物の固いColliderは保持します。Tilemap上の建物は入口前に空のGameObjectを置き、
そのオブジェクトを選んで同じメニューを実行してください。
手動で設定する場合は、入口Triggerの `MapBuildingAccess.BuildingType` を `Blacksmith` にし、
ルーターの `Blacksmith Inventory` にシーン内の装備インベントリを割り当てます。
未指定の場合もシーン内の非アクティブなインベントリを検索して再利用します。

取得した装備に `sourceMapId` を保存するため、プレイヤーの現在地が変わっても
費用・素材は出身マップを参照します。旧装備は `MapSO.dungeonEquipment` から
出身を特定します。初期装備 `EQP_001` / `EQP_002` は `MAP_001` を使います。
旧装備に複数の出身候補がある場合は、費用を決めず設定エラーを表示します。

`Assets/Resources/Data/MapCatalog.asset` を追加しました。
カタログはEditor起動時・マップCSVインポート後・ビルド前に更新します。
手動更新は「MixMaster > Data > マップカタログを更新」です。
各マップにボスと、異なる固有素材を持つモンスター6種を設定してください。
既存の装備インベントリPrefabはそのまま使用できます。

画面無効化による停止と保存も検証しました。不足で停止してから時間を置いて
指を離した際に追加購入が起きないよう、解放クリックの抑制を補強しています。
Unityエディターでの全体コンパイル・ネイティブUI入力・実機表示は未実施です。

Playモードでは、短いタップ、長押し、指を離す／外へ動かす、素材不足時の停止、

## 再錬成（2026年11月4日）

鍛冶屋から装備一覧を開き、装備を選択して「強化」へ進むと、画面下部に「再錬成」が表示されます。＋50の最大強化後も実行できます。通常インベントリからは鍛冶屋用画面を開けません。

- 費用は、通常強化と同じ **モンスター素材6種を各50,000個（合計300,000個）**。ゴールドとダンジョン固有素材は再錬成では消費しません。6種の取得処理は通常強化と共通です。
- 毎回、**現在の強化前レベル±10**とLv.1〜100の共通範囲にある整数を等確率で抽選します。例：強化前Lv.50なら40〜60、Lv.1なら1〜11、Lv.100なら90〜100。次回は再抽選後の強化前レベルが基準です。
- 強化回数は保持します。強化前Lv.50・＋20の装備がLv.44を引くと、実効Lv.64・＋20になります。
- **ドロップ率＋1〜100％**を整数で等確率抽選します。現在の再錬成補正へ上書きし、加算蓄積しません。
- 再錬成のドロップ率は独立した加算値です。＋80％は0.8として既存の装備補正へ加算し、装備レベルや強化回数では増幅しません。既存のドロップ率ステータスが作用する範囲へ反映し、モンスター加入率の独立抽選ルールは維持します。
- 実行前に素材名・費用・抽選範囲・上書きを確認できます。キャンセルは消費せず、確定時にも所持数と装備を検査します。素材消費と装備更新を済ませてから通知するため、通知中の再入実行も拒否します。
- 素材が未設定、出身マップ不明、装備定義なし、素材不足では実行しません。出身は強化と同じsourceMapId／MapCatalogの対応を使います。

装備一覧、選択した装備の詳細、主人公の装備一覧、強化の現在値／次レベルプレビューで、付与分を **水色「再錬成 ドロップ率＋○％」** の専用行として表示します。通常の補正行へ付与分を二重計上せず、ソート・絞り込み・比較・実際のステータス計算には合計値を使用します。

EquipmentRecord.reforgeDropRatePercentを既存の共通セーブへ保存します。旧セーブは0（未再錬成）で、復元時に0〜100へ正規化します。強化・装備変更・プリセット切替でも現物の補正を維持します。再錬成成功後は既存SaveManagerへ即時保存を依頼し、通常の定期保存も継続します。Scene・Prefab・.metaは変更せず、既存のコード生成強化画面へ部品を追加します。

実装した装備管理・強化・素材管理・表示・保存レコードを、Unity／カタログ／JSONバックエンドを代替した環境で230項目検証しました。強化／確認画面の実クラス・Factoryもコンパイルし18項目検証（＋50での実行、確認／キャンセル、素材再検査、古いプレビュー拒否、画面終了、通常一覧からの禁止、成功時の保存呼出し）しました。保存テストは実SaveManagerのディスクI/OやUnity JsonUtilityでのネイティブ実行ではありません。

Unity本体の全体コンパイル・Play・実機描画は未実施です。Unityでは鍛冶屋→強化→再錬成を開き、素材6種を各50,000個、抽選後の強化前Lvと＋回数、各画面の水色補正、主人公／仲間のドロップ率、通常強化後と再起動後の維持を確認してください。


2026年11月4日（素材指定変更）：通常強化と同じ出身マップのモンスター素材6種を各50,000個へ変更しました。通常強化と再錬成の素材収集処理を共通化し、＋50でも費用を取得できます。6種全部を確認してからまとめて消費し、1種不足でも他素材を減らしません。再錬成欄へ6種の素材スプライトと「×50,000」・所持数を表示し、確認画面にも合計300,000個を記載します。ダンジョン素材は消費しません。実装備/素材/費用の代替API検証123項目成功（6種それぞれ不足・全消費・通知時一貫性・再入・＋50・通常強化との一致・重複旧枠）。Unity本体の全体コンパイル/Play/表示確認は未実施です。

## 再錬成研究（ダンジョン強化）

ダンジョン入口の強化項目へ「再錬成研究」を追加しました。そのマップのダンジョン素材50,000個で研究Lvを1上げ、同マップ産の装備の再錬成ドロップ率の最低保証を1ポイント上げます。

研究Lv.0は1〜100％、Lv.1は2〜100％、Lv.49は50〜100％です。最大保証50％に達するまで49回、各50,000個の固定費用です。既存の適用Lvの最小/減少/増加/最大操作も使え、抽選下限は「1＋適用研究Lv」となります。出身マップは強化・素材費用と同じsourceMapId／MapCatalogで解決します。他マップの研究は影響しません。既に再錬成済みの補正は自動変更せず、次回の再錬成から保証します。

研究に使うのはダンジョン素材、再錬成の実行に使うのは従来どおり通常強化素材6種を各50,000個です。購入は既存のダンジョン強化のタップ/長押し・まとめ保存を使用します。MapAltarProgressRecordのreforgeResearchLevel/appliedReforgeResearchLevelに既存の共通セーブで保存し、旧セーブは0で始まります。DungeonUpgradeTypeは末尾へID 7を追加し、既存0〜6を保持します。

DungeonEntrancePanel.prefabに研究行を追加し、スクロール内容を延長しました。既存7行の配置/IDとPrefabのGUIDを保持し、利用者のシーン配置は変更していません。旧unpackedパネルには初回だけ研究行を既存行から補完します。
