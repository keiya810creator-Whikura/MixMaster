# 編集可能なゲームUI

MainSceneのCanvasには、オフライン報酬HUD・ダンジョン挑戦パネル・リザルトパネルを配置済みです。
UIはPlay中にコードで組み立てる方式から、Prefab内の参照済みオブジェクトを表示・更新する方式に変更しました。

## Prefabの配置と編集

すべて `Assets/Prefab/UI/` にあります。

| Prefab | 用途 |
| --- | --- |
| `OfflineRewardsHUD` | 下記3つのオフラインUIと接続用コントローラーをまとめた配置用Prefab |
| `OfflineRecordButton` | 記録開始・記録中の残り時間・中止ボタン |
| `OfflineRecordingPanel` | 素材アイコン付きの1分当たり取得数・上書き確認 |
| `OfflineRewardReceiptPanel` | 素材アイコン付きのオフライン受取結果 |
| `RewardItemRow` | アイコン・名前・数量の共通行。ダンジョンの獲得装備行も共用 |
| `DungeonEntrancePanel` | 称号付与率・7種類のダンジョン強化・適用レベル・挑戦・閉じる |
| `DungeonResultPanel` | 実際の獲得素材・装備一覧・装備詳細への接続・再挑戦・帰還 |
| `PlayerStatusMenuPanel` | 既存ステータス画面。自動攻撃トグルを追加 |

Prefabを開き、ボタンやCardのRectTransform、Image、TMPの設定を編集してください。
各画面の操作部分は子の `SafeArea` 以下にあります。ノッチ・ホームバーへの対応は `Docs/MobileSafeArea.md` を参照してください。
配置・サイズ・色は表示時にコードで再生成しません。素材・数値・残り時間・ON/OFFなどの可変情報はコードで更新します。
受取・記録結果・ダンジョン画面のルートは初期状態を非アクティブにします。
一覧の行間・高さはContentのVerticalLayoutGroupと `RewardItemRow` のLayoutElementで編集できます。
挑戦パネルの7つの強化行もPrefab内に配置済みなので、それぞれ編集できます。

別シーンでは、Canvas下へ `OfflineRewardsHUD`・`DungeonEntrancePanel`・`DungeonResultPanel` を各1つ配置してください。
`MapBuildingUIRouter` の Dungeon Entrance Panelに挑戦パネルのシーンインスタンスを設定します。未設定の場合も非アクティブを含めて検索します。
リザルトは配置済みのパネルを検索して再利用します。ダンジョンの「帰還（仮）」と開発中の注記は生成しません。

## 表示と操作

- 3分間の記録が通常プレイ中に完了したときは、記録結果と上書き確認を表示します。
- 復帰時・起動時は、確認待ちの記録があっても記録画面を開きません。「記録結果を確認」ボタンで開けます。
- 復帰時に報酬が付与された場合は受取画面を表示します。この画面の「閉じる」は記録の上書きを行いません。
- 主人公のステータス画面にある「主人公の自動攻撃」のチェックでON/OFFを切り替えます。現在の設定と同期し、変更はセーブします。
- 仲間の攻撃範囲は、近接・遠距離の実際の有効射程で表示します。縮小された仲間でもワールド上の半径を維持し、死亡時は非表示、復活時は再表示します。
- 共通の仲間Prefabには主人公と同じ円を追加しました。独自の仲間Prefabに円がない場合は主人公の円を複製して接続します。色・透過度・表示ON/OFFは円の `PlayerAttackRangeIndicator` で編集できます。

## Unityでの確認

1. MainSceneを開き、Prefab参照がMissingになっていないことを確認します。
2. 「記録モード（3分）」を押し、完了後に素材アイコン・取得量・上書き確認が表示されることを確認します。
3. 未確定の結果を残したままバックグラウンドへ移動し、復帰時に記録画面が開かないことを確認します。獲得報酬があれば受取画面だけを表示します。
4. ステータス画面で自動攻撃をOFFにし、実際の自動攻撃が停止すること、再起動後もOFFになることを確認します。
5. 仲間の近接・遠距離射程、装備変更後の射程、死亡・復活時の円を確認します。
6. ダンジョン入口で7種類の強化と適用レベルを操作し、挑戦・クリア・装備詳細・再挑戦・帰還を確認します。再挑戦後もパネルを再利用します。
