# ゴールド表示と命中エフェクト

## ゴールド表示

`Assets/Prefab/UI/GoldCounterHUD.prefab` を追加し、MainSceneの
`Canvas/GoldCounterHUD` にPrefabインスタンスを配置しています。
再生前からHierarchyで位置・大きさ・背景Imageを編集でき、子の
`GoldValue` でフォント・文字サイズ・文字色を調整できます。
`GoldCounterHUD` の `Prefix` / `Suffix` で金額の前後の文字を変更できます。

実行時は保存済み所持Goldの読み込みと `GameManager.GoldChanged` による
数値更新だけを行います。プレイヤー・仲間HUDからの自動生成と、
起動時の背景・文字スタイルの上書きを削除しました。

別シーンにはPrefabをCanvasへドラッグするか、
「MixMaster > UI > ゴールド表示HUDを配置」を実行してください。
既存のHUDがある場合は再利用し、位置や見た目を維持します。
プレイヤー・仲間の円形HUDの作成メニューからもEditor上で配置します。

## 命中パーティクル

`DamagePopupText.Show` から共通の `DamageHitParticles` を呼び出します。
主人公・仲間・敵の近接／魔法攻撃の実ダメージ表示と同じタイミングで、
被弾側の位置に短い放射状の粒子と中央のフラッシュを出します。
ダメージが0以下の場合は表示しません。

色はダメージテキストと共通の値を渡します。

| 攻撃元 | テキスト・パーティクルの色 |
| --- | --- |
| 主人公／不明 | 白 |
| 仲間1 | 赤 |
| 仲間2 | 青 |
| 仲間3 | 緑 |
| 敵（主人公・仲間の被ダメージ） | 黒 |

`Assets/Resources/Effects/DamageHitParticle.mat` と
`Assets/Shaders/DamageHitParticle.shader` を使います。
黒い粒子も描画できるアルファブレンドで、外周をぼかした円形です。
点灯の色だけを共有し、消える際は透明度を下げます。

最大32個のバーストを同時表示し、終了したオブジェクトは再利用します。
敵を倒した直後も演出は最後まで残り、ポーズ中はゲーム時間に合わせて停止します。
ダメージテキストが表示上限に達しても、空きがあればパーティクルを表示します。

## 検証

実際のHUD・ダメージ表示・パーティクル・配置メニューのC#ソースを
API代替環境でコンパイル・実行し、金額更新、購読解除・再接続、
スタイル維持、全攻撃元の色一致、粒子の再利用と上限、無効なプール参照、
テキスト上限中の粒子表示、配置メニューの重複防止を確認しています。
Prefab・シーン・Materialの参照も静的に検証しています。

Unityエディター本体での全体コンパイル、Prefabのインポート、
GPUでのパーティクル描画、端末上の見え方は未実施です。
適用後は近接・魔法それぞれの命中、撃破時、連続命中時、ポーズ中の表示を確認してください。
