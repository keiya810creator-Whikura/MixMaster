# スキルの取り込みと使用

発射物の14種類の移動、回転・貫通・分裂・連鎖等の設定は [ProjectileSettings.md](ProjectileSettings.md) を参照してください。

## 最初に使う

添付された数字IDのスキル表から、ID「1」〜「12」の初期スキルアセットと一覧を同梱しています。
主人公は人間の書の習得一覧から、レベルとスキルポイントの条件を満たしたスキルを習得できます。
画面の「スキル設定」を開き、スキルを選んで「習得」、使用枠を選んで「登録・条件を保存」を押してください。
主人公の五つの発動ボタンから使用できます。自動発動を使う場合は条件も設定します。
ポイントがない場合はレベルアップで獲得してください。勝手にポイントや習得スキルを付与する処理はありません。

転生後は転生先の `MonsterSO.availableSkills` が習得可能一覧になります。
転生時は習得と使用枠をリセットし、従来どおり使用済みスキルポイントを返却します。
人間の習得一覧は `Assets/Resources/Skills/SkillCatalog.asset` のHuman Skillsで編集できます。

## Excel・CSVの取り込み

Unityを停止し、`MixMaster → スキル → Excel・CSVを選んで取り込む` から `.xlsx` を選択します。
「スキル」シートを直接読み込みます。Excelアプリ・外部パッケージの追加は不要です。
一行一スキル、日本語の列名・選択肢、数字IDに対応します。CSV、添付のようなMarkdown表も読み込めます。
IDは文字列として参照し、Excelの数値「1」や「1.0」はID「1」へ正規化します。

既定ファイルを使う場合は `Assets/DataCSV/スキル.xlsx` に置き、`既定のスキル表を取り込む` を実行してください。
Excelがなければ同じ場所の `スキル.csv` を使用します。初期CSVは添付表をUTF-8 BOM付きにしたものです。
既存の `MixMaster → CSV → 一括取り込み` でも、スキルをモンスターより先に取り込みます。

発射物の速度・寿命・追尾は、式の保存キャッシュに頼らず、発動形式と右端の入力欄から決定します。
即時では速度・寿命0、追尾無効。元の値が入力欄に残っていても使用しません。
追尾は日本語の有効／無効に加え、既存表の真偽値・0/1も読み込めます。

全行の値を検証してから更新します。重複ID、未知の選択肢、負数、非数、整数の範囲外、不正な画像参照、無効な追加効果は行番号付きエラーになります。
既存の同じIDのSkillSOをその場で更新し、GUIDとモンスター側からの参照を維持します。
表から行を消しても既存アセットは削除しません。画像・演出の空欄は更新時に既存指定を維持します。
発射物の行には、番号付きSpriteを `Assets/素材/Profectile` または `Assets/素材/Projectile` に配置してください。
取り込み時に `Assets/Resources/Skills/Projectile/番号.prefab` を作成・更新し、SkillSOへ自動設定します。
動作・色・サイズなどは表で管理します。詳細と空欄の初期値は [ProjectileSettings.md](ProjectileSettings.md) を参照してください。

## モンスターの習得と敵の使用

既存のモンスターCSVへ次の列を追加・編集します。他の既存列は残してください。

| 列名 | 内容 | 例 |
| --- | --- | --- |
| 習得可能スキル | 仲間・転生で習得できる一覧。旧SkillIdsも対応 | 1;2;3 |
| 敵使用スキル | 敵として自動使用する一覧。EnemySkillIdsも対応 | 1;12 |

「スキル」表を先に取り込んでからモンスターCSVを取り込んでください。
既存のモンスターに勝手にスキルを付けることはありません。
旧初期データの `SKILL_001` などは仮スキルです。使用するモンスターの習得可能一覧を `1;2;3` などの数字IDへ変更して取り込んでください。
敵の使用一覧が空なら通常攻撃だけです。出現後、各スキルの再使用時間が経過してから最初の発動を試します。
敵も同じMP消費・射程・詠唱・効果を使い、対象不在やMP不足では待機します。
スキル射程のために追跡距離を伸ばす変更はしていません。既存の索敵・接近AIが動きます。

仲間の設定は「スキル設定」の対象から選びます。習得・使用枠・自動条件を個体ごとに保存します。
攻撃禁止モードでは仲間の自動スキルも発動しません。回復は生存している同陣営が対象で、自分も含みます。
単体回復・支援は射程内で体力割合が最も低い味方、単体攻撃は近くの敵を選びます。

## 使用枠とトリガー

主人公・仲間は一人五枠まで。同じスキルの重複登録は移動として扱います。
手動ボタンと自動条件は同じ再使用時間を共有します。
第一条件が「手動のみ」なら自動発動なし。追加条件が「追加条件なし」なら第一条件だけを見ます。
第一条件と追加条件はAND、別の枠が別のルールになります。優先度が大きい順、同値は枠順です。

| 条件 | 数値 |
| --- | --- |
| 使用可能になったら | 使用しない |
| 自分の体力％以下 | 0〜100 |
| 自分のMP％以上 | 0〜100 |
| 対象の体力％以下 | 0〜100 |
| 攻撃範囲内の敵の数以上 | 1以上 |
| 通常攻撃が指定回数命中 | 1以上 |
| 指定回数ダメージを受けたら | 1以上 |
| 指定秒数ごと | 秒数。最短0.2秒 |
| 指定数の敵を倒したら | 1以上 |

例：ヒーリングを「自分の体力50％以下」、剛力の加護を「使用可能になったら」、衝撃波を「敵が3体以上、かつ自分の体力50％以下」に設定できます。
回数条件は登録後の回数を数え、発動成功時に消費します。通常攻撃一回の複数命中は一回として数えます。
スキル由来のダメージ・討伐からトリガーを連鎖させません。無限発動を防ぎます。
通常攻撃の会心・戦闘開始専用の条件、任意の対象をタップして指定する機能は今回含めていません。

## バフ・デバフ・状態異常

即時では実行時、発射物では命中時に基本効果を適用し、生存している対象へ追加効果を順番に付けます。
基本効果「なし」なら支援専用です。基本効果と追加効果は表の「適用先」を共用します。
範囲効果は一体一回、距離順で命中上限まで。複数Colliderがあっても重複しません。

- バフ・デバフ：攻撃力、魔法攻撃力、防御力、魔法防御力、移動速度、攻撃速度、攻撃範囲に対応。割合は元の能力に対して加算。元データは書き換えません。
- 毒・火傷：固定値または対象の最大体力割合で継続ダメージ。付与直後の追加ダメージなし。間隔ごとに実行し、持続時間ちょうどの回も含みます。防御・会心の影響なし。
- 凍結・麻痺：移動、通常攻撃、スキルを停止。
- 睡眠：同じく行動停止し、ダメージを受けると解除。
- 沈黙：スキルだけを停止。
- 暗闇：攻撃が50％の確率で外れます。回復には影響なし。
- 混乱：通常攻撃を自分以外の近くの敵味方へ無作為に行います。スキルの対象も敵味方を区別しません。

時間更新・重ね掛け・無視に対応します。同じスキルIDと追加効果番号を重複単位にします。
重ね掛けは上限まで効果量を加算し、残り時間を共有します。別の使用者からも同じ単位です。
能力の最小値を制限し、移動・攻撃速度・範囲は0.1未満にしません。
継続ダメージにも元の使用者を記録し、素材・経験値等は既存の討伐処理へ渡します。

## UI編集と保存

`Assets/Resources/Skills/SkillHUD.prefab` に五つの発動ボタンと設定パネルを用意しています。
シーンの画面用Canvasへ自動で配置します。SafeArea配下の配置・文字・サイズをPrefabで編集できます。
`MixMaster → スキル → スキルUIプレファブを作成・配置` でも配置できます。既存Prefabを上書きしません。
Prefabがない場合は同じ配置をコードで作成するフォールバックがあります。

セーブをバージョン14へ拡張しました。既存セーブは未習得・未登録から始まります。
習得と設定はセーブし、使用ポイントは既存の主人公/仲間データに保存します。
画面遷移で同じ個体の再使用時間を維持します。アプリ再起動・ロード後は登録スキルの通常の再使用時間から開始します。
一時的な状態異常・詠唱・弾はセーブせず、死亡・シーンの個体破棄・起動時に解除します。
ポーズ中はスキル時間を停止し、オフライン中にスキルの発動や継続ダメージを計算しません。

## 装着パッシブ・配合継承・共通エフェクト（2026-10-26）

`Docs/SkillTemplates/スキル定義テンプレート.xlsx` を入力例として使用できます。既存の取り込みメニューで選択してください。1行1スキル、数字ID、既存の5枠をアクティブとパッシブで共有します。既存のID・GUID・セーブフィールドは維持しています。

### 共通エフェクト

| 列 | 選択肢・動作 |
| --- | --- |
| 生成位置 | 使用者／対象。空欄は使用者 |
| 追従先 | 追従なし／使用者／対象。指定時は旧「使用者に追従」より優先 |
| 効果発生タイミング | 命中時／生成時／一定間隔。空欄は従来の命中時 |
| 効果間隔秒 | 0.02以上、空欄1。最初の効果もこの秒数を待って発生 |

ヒール・バフは「発射物、その場、対象に生成、対象追従、生成時」に設定すると、対象へ1回効果を付けてから表示寿命まで残ります。陣は「その場、追従なし、一定間隔、範囲内の敵／味方」と範囲半径で設定できます。速度入力は既存のチェックに合わせ正数（その場なら1）にしてください。表示寿命と追加効果の持続秒は独立です。番号画像は既存どおり `Assets/素材/Projectile` または `Profectile` に配置します。画像の不足時は取り込みが止まります。

### パッシブ

`スキル種別=パッシブ` とし、`パッシブ1～3_効果`、`パッシブ1～3_効果量` を指定します。発射物やMP消費、自動発動条件、追加効果は使用しません。習得だけでは有効にならず、枠から解除すると効果が消えます。重複する同一IDは加算しません。

- 最大HP・最大MP・攻撃力・魔法攻撃力・防御力・魔法防御力・移動速度・攻撃速度・攻撃範囲・会心倍率：10で元の値に＋10％。本人へ適用。
- 会心率・素材ドロップ率・属性耐性：10で＋10ポイント。会心率上限100％、耐性上限80％。モンスター本体入手率には影響しません。
- 火・水・風・雷・光・闇・全属性耐性を選択可能。
- 近接／遠距離攻撃タイプ：本人の通常攻撃を変更。効果量は0で可。両方装着なら後ろの枠、同じスキル内なら後ろの効果を優先。遠距離の射程は通常範囲の2倍。主人公は魔法弾、仲間は既存の弾設定（未設定なら既存の魔法ダメージフォールバック）を使います。
- 装備ドロップ率：ダンジョン通常敵の装備抽選に加算。10で＋10ポイント、上限100％。
- 配合確率：成功率へ加算、上限100％。
- 武器取得数：ダンジョン最終ボスの保証装備取得数へ加算。装備種類の抽選は従来どおり。
- 称号抽選回数：本体入手時に追加抽選。称号が付いたら終了し、既に付いた称号は置換しません。追加は合計1000回まで。
- 敵リスポーン速度：祭壇補正後の待機時間を `1＋合計効果量÷100` で割ります。100で速度2倍、待機時間半分。変更後に計算する待機時間から適用。

共通効果（装備ドロップ・配合・武器数・称号回数・リスポーン）は主人公＋編成中仲間の装着分のみ集計し、控えは除外します。個数系の入力は0～1000の整数です。

既存カタログの人間の習得一覧は自動で増やしません。主人公で新規パッシブを習得するには SkillCatalog の humanSkills または転生種族の習得可能一覧へ追加してください。モンスターは従来どおりモンスター表からスキルIDを参照します。

### 配合と条件UI

配合成功時、両親のセット中スキルからIDの重複を除いてランダムに最大3つを習得済みとして引き継ぎます。候補が3未満なら全候補、未装着の習得スキルは候補外です。枠には自動装着せず、子の種族に通常の習得資格がないスキルもパネルから登録できます。失敗・中止時は子への継承を行いません。

仲間選択時は第1条件から「手動のみ」を除外します。保存APIでも仲間の手動条件を「使用可能になったら」に補正します。AND側の「追加条件なし」は利用できます。パッシブ選択時は条件欄を無効化します。
