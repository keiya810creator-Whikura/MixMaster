# 配合・村への復帰・転生の書

## スキルポイント

配合成功時、両親の「未使用ポイント＋使用済みポイント」の合計を、
子の未使用スキルポイントとして引き継ぎます。子の習得スキル・使用済みポイントは0からです。
失敗時の親の消費／保護ルールは既存通りです。ポイントは最大int値で飽和し、負数を加算しません。
子の取得イベントを通知する前にポイントを設定します。

主人公もレベルアップごとに1ポイント獲得します。転生時には未使用・使用済みの合計を
未使用ポイントとして保持します。Lvは1、経験値は0、HP・MPは全回復になります。
転生の書は消費しません。転生前にパネル上でリセット内容と引き継ぐポイント数を確認できます。

## 転生の書

- 人間の書は初期所持で、常に選択できます。
- 個体の信頼度が5以上になると、その種族の書を一度だけ入手します。
- 信頼度は既存の `MonsterIntimacyBalance` に従います。Lv5は累計100討伐です。
- 書は種族IDで管理し、別個体でも重複しません。元のモンスターを売却・配合しても残ります。
- 取得済みの書とお気に入り状態を保存します。
- 既存セーブに信頼度5以上の個体がいる場合、ロード時に未取得の書を補完します。

`ReincarnationManager` が一覧・取得・お気に入り・転生を管理します。
モンスターの書は `MonsterSO.monsterId`、人間は `HUMAN` をIDに使います。
信頼度の変化を購読し、条件達成時に書を追加して保存します。

## 成長とスキル

モンスターの書で転生すると、その種族の基礎値をLv1の能力値として設定します。
以降のHP・MP・攻撃・魔力・防御・魔防は、1レベルにつきその基礎値を加算します。
例：基礎HP11、攻撃7ならLv2でHP22、攻撃14です。
クリティカル・移動速度・攻撃間隔・射程・属性耐性は基礎値を保持し、レベルでは増加しません。
書には個体値・称号・信頼度の倍率を引き継ぎません。装備補正は従来通り反映します。

人間の書では、GameManagersのPlayerManagerに設定された初期基礎値へ戻ります。
人間の成長は従来のHP+5、MP・攻撃・魔力・防御・魔防+1です。

転生先の `MonsterSO.availableSkills` を
`PlayerManager.AvailableReincarnationSkills` から参照できます。
パネルにも一覧の概要を表示します。スキルの習得・使用・発動処理は今後の実装です。

## 祭壇とパネル

MainSceneの既存の「転生の祭壇」に `ReincarnationAccessTrigger` を配置し、
接触で転生パネルを開くよう接続しています。祭壇本体の固いColliderは維持します。
開いている間は移動とジョイスティック操作を止め、閉じると解除します。

`Assets/Prefab/UI/ReincarnationPanel.prefab` はCanvas下に配置済みの編集可能なPrefabです。
書のカードは `ReincarnationBookEntry.prefab` を再利用し、モンスターのスプライトを背景に表示します。
入手順・名前・基礎HP・MP・攻撃・魔力・防御・魔防でソートでき、昇順／降順を切り替えられます。
カードの☆／★でお気に入りを切り替え、★のみの絞り込みもできます。
お気に入りフィルター中も、専用の「人間の書」ボタンから人間を選べます。

別の祭壇を設定する場合は、Hierarchyで選び
「MixMaster > Map > 選択した転生の祭壇を設定」を実行します。
既存Trigger・パネルを再利用するため、途中状態から再実行できます。

## 起動時の村中央リスポン

セーブされた能力値・所持品等をロードした後、村を有効にして中央付近へ戻ります。
中央に障害物があれば、周囲8マス以内の最も近い通行可能セルを選びます。
物理速度、主人公の移動履歴、仲間の配置、カメラ追従も更新します。
戦闘不能の状態で保存されていた場合はHP・MPも回復します。
セーブに残った探索マップやダンジョン入口の座標は起動位置に使いません。

MainSceneの `TilemapMap_村/VillageStartPoint` を設定済みです。
`Use Map Center` を外すと、このオブジェクトの位置を出現位置として使えます。
別の村は「MixMaster > Map > 選択した村を起動地点に設定」で設定できます。

## 保存互換性と検証

保存バージョンは10です。古いセーブの主人公は人間として復元し、
未実装だったスキルポイントには保存Lv−1を初期値として与えます。
モンスター、装備、素材、Gold、祭壇等の既存データを維持します。

実際のC#ソースをAPI代替環境でコンパイル・実行し、配合のポイント継承、
信頼度の取得境界、重複防止と永久所持、旧セーブの補完、転生成長、人間への復帰、
スキル一覧、ポイントの飽和、保存復元、ソート・お気に入り・絞り込み、転生確認・キャンセル、
祭壇接触と移動制御、パネルの閉じる／無効化／切り替え、村中央復帰を確認しています。
Prefab・シーン・マネージャーの参照も静的に検証しています。
Unityエディター本体の全体コンパイル、Prefabインポート、ネイティブUI・物理接触の確認は未実施です。
