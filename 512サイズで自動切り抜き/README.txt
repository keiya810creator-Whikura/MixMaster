AutoSplitSprites512 v3
========================

今回の修正
----------
前バージョンでは、複数モンスターを「離れたパーツ」と誤認して
1つにまとめる場合がありました。

v3では、

・大きな本体同士は絶対に結合しない
・小さな武器、角、影、エフェクトだけを最寄りの本体へ追加
・それでも1つに繋がった場合は、白い空白帯で自動分割

という方式です。

例
--
1枚に6体:
InputSprites/monster.png

出力:
Output512/monster/
  monster_01.png
  monster_02.png
  monster_03.png
  monster_04.png
  monster_05.png
  monster_06.png

各画像:
・512x512
・縦横比維持
・長辺を約96%まで拡大
・中央配置

使い方
------
1. InputSprites に画像を入れる
2. Run_AutoSplit512_v3.bat を実行
3. 黒い画面に「検出数: 6」のように表示される
4. Output512 を確認

重要
----
もし「検出数」が実際の数と違う場合、
その元画像をChatGPTに添付してください。
その画像の配置・背景・影に合わせて検出条件を調整できます。
